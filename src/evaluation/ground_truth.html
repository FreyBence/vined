Metric reference

Reference scores use the target itself as a prediction on the same scoring support. They describe a perfect data-only reference, not a trained model. R² and cosine are 1 where defined. Reference BPS uses the saturated Poisson likelihood relative to the recorded mean-count baseline; it is not a fixed value of 1. Undefined scores remain unavailable.

Each evaluation's aggregate includes its own recorded population and weighting policy.
